## 一、爽点：赢大池的仪式感

### 触发阈值（三条任一）

- 单池赢 **> 30 个大盲**
- 赢额 **> 当前筹码的 50%**
- **全下并赢**（不论金额）

普通赢保持现状（上行四音 + 数字跳），只有大赢触发下面的表现。

### 表现

1. **屏幕轻震**：`.app` 加 `bigWinShake .38s`，`translateX` ±3px 来回两次，只震一次
2. **筹码飞入**：结算弹层弹出前约 600ms，从底池中心生成 10 个小圆片，沿贝塞尔曲线飞向自己座位，落地各响一声 `chip`（音高随机 ±15%）
3. **牌面逐张翻开**：全下摊牌时对手手牌先显示牌背，每 150ms 翻一张

### 技术

- 新增 `celebrateBigWin()`，在 `showResult()` 开头按条件调用
- 筹码圆片用 `position: fixed` DOM，动画结束移除
- 约 80 行 JS + CSS

### 验收

- 赢 600+ 筹码：震动 + 飞筹码
- 赢 100 筹码：不触发
- 全下赢 50 筹码：触发

## 二、目标感：挑战模式

### 三种模式

| 模式 | 规则 | 失败条件 |
|---|---|---|
| **生存** | 100 手内不破产（初始 2000） | 筹码归零 |
| **冲刺** | 30 手内从 2000 打到 3000（+50%） | 手数用完或归零 |
| **翻倍** | 50 手内从 2000 打到 4000（×2） | 同上 |

### 核心改动

**挑战中关闭自动补码**——现在输光自动补 2000，等于没有失败。挑战里必须真的会输。

### 状态结构

```js
challenge = {
  active: true,
  mode: 'sprint',        // survival | sprint | double
  startChips: 2000,
  targetChips: 3000,
  handsTotal: 30,
  handsLeft: 27,
  result: null           // 'win' | 'lose' | null
}
```

### 每手结束检查

```
玩家筹码 >= targetChips  → 通关
handsLeft <= 0           → 失败（手数用光）
玩家筹码 <= 0            → 失败（破产）
```

### 失败处理

**筹码清零**，回到普通模式，需要重新开挑战。

### UI

- 顶栏常驻：`冲刺 · 27/30 手 · 2840/3000` + 进度条
- 顶栏「挑战」按钮，弹层选模式（显示历史最好成绩）
- 通关：金色「通关」+ 用时 + 最高筹码
- 失败：灰色 + 差多少 + 「再来一次」

### 存档

```js
poker.challenge.v1 = { best: { survival: 88, sprint: false, double: false } }
```
生存记撑过多少手，冲刺/翻倍记是否通关 + 最少用了几手。

### 成本

约 180 行，引擎不改。

## 三、新手引导：首次打开弹提示条

### 流程

1. 首次打开（`poker.guide.v1.done` 不存在）→ 底部弹一条提示条：
   > 「第一次玩？要不要看一遍手把手的引导？」　[看一遍]　[不用了]
2. 选「看一遍」→ 进入引导模式，走一手带讲解的牌
3. 选「不用了」或走完 → `done = true`，永不再现

### 六步讲解

| 步 | 时机 | 说什么 |
|---|---|---|
| 1 | 发完底牌 | 「这两张是你的底牌，只有你能看见」 |
| 2 | 第一次轮到你 | 「花 10 个筹码就能看翻牌，点这里跟注」+ 按钮脉冲 |
| 3 | 翻牌发出 | 「这三张是公共牌，所有人都能用」 |
| 4 | 转牌 | 「第四张，底池越来越大了」 |
| 5 | 河牌 | 「最后一张，接下来比大小」 |
| 6 | 结算 | 「你赢了/输了，原因：……」+ 「点这里看复盘」 |

### 技术

- 讲解用现有 `showBubble()`，说话者是自己座位
- 要点的按钮加 `.hint` 类（脉冲动画）
- 不新建状态机：靠 `game.street` + `game.activeSeat` + `guideStep` 变量推进
- `?guide=1` 强制触发（方便测试）

### 成本

约 150 行。

## 四、AI 之间聊天

### 四条铁律

1. **只聊公开信息**：下注、弃牌、摊牌结果。绝不评论自己手牌
2. **不刷屏**：每手最多 2 句，整桌共享
3. **性格靠语气，不靠标签**：紧手说话短、疯子带感叹号、跟注站爱说「看看」
4. **要有来有回**：A 说完 B 有概率接话，这才是聊天不是广播

### 四类对话

**1. 行动台词**（已有，扩充到每类 10–12 句，按性格分组）

```js
SAY = {
  aggressive: { raise: ['加！', '来啊', '别磨蹭', '加点'], fold: ['……'] },
  tight:      { raise: ['加注'], fold: ['不跟了', '让给你'] },
  station:    { raise: ['跟'], fold: ['算了', '这次真弃了'] }
}
```

**2. 回应**（新增，聊天的核心）

触发：某人加注 > 底池 1/2、全下、大额跟注时，另一个未弃牌玩家 30% 概率接一句：

```js
REPLY = {
  to_raise: ['又加？', '你真有牌？', '跟不跟呢', '这尺寸有意思'],
  to_allin: ['别唬我', '全下？', '这手我接'],
  to_fold:  ['就知道你会弃', '又跑了', '没意思']
}
```
延迟 1.2 秒，让对话有节奏。

**3. 互相调侃**（新增，低频）

触发：连续 ≥3 手没人说话，25% 概率随机两个 AI 一来一回：

```js
BANTER = [
  ['你手气不错啊', '还行还行'],
  ['这桌太难打了', '你刚赢了一把'],
  ['我牌都烂透了', '我也是'],
  ['别急，等他犯错', '你倒是不急']
]
```
两句间隔 1.5 秒。

**4. 摊牌反应**（新增，最有戏剧性）

- 赢家拿大池：对手说「运气不错」「下次我不会跟了」
- 赢家拿空气牌赢摊牌：「你刚才一直在唬我？」
- 被同一人连赢两手：「你今晚吃定我了？」

### 技术

```js
function say(seat, text, delay)
function maybeReply(actorSeat, action)
function maybeBanter()
```

- 频率用每手计数器 `_talkBudget`（初始 2，说一句 -1）
- 全下/大池场合 +1 额度
- 消息仍写入 `hands.v2.messages[]`，牌谱能回看

### 风险

- 最怕刷屏 → 严格每手 2 句上限
- 最怕假 → 句长控制 2–6 字
- 不能泄牌 → 台词只引用已发生的事实

### 成本

约 120 行（文案 60 + 逻辑 60）。

## 五、进度感：等级 + 里程碑

**不做每日任务**这类会绑架人的设计，只做被动累积。

### 等级（累计手数）

| 称号 | 手数 |
|---|---|
| 新手上桌 | 0 |
| 常客 | 100 |
| 老手 | 500 |
| 牌桌灵魂 | 2000 |

升格时弹一个小提示，不打断牌局。

### 里程碑（8 条）

| 名称 | 条件 |
|---|---|
| 第一桶金 | 第一次赢底池 |
| 大赢家 | 单池赢 5000 |
| 铁头 | 连续 10 手不弃牌 |
| 亡命徒 | 全下赢 3 次 |
| 翻身 | 从 1000 打到 5000（一局之内） |
| 马拉松 | 累计 2000 手 |
| 挑战者 | 任一挑战模式通关 |
| 天选 | 拿到四条或以上并赢下 |

展示：统计弹层加一页「成就」，未解锁显示灰色问号。

### 存档

```js
poker.profile.v1 = { hands: 0, level: 0, achievements: { firstWin: true } }
```

### 成本

约 200 行。
