# AI 难度分级改造报告

> 目标：让三档难度（新手 / 熟练 / 职业）拉开真正的实力差距，而不是"同一个 AI 换个参数"。

---

## 一、改造前的问题

原来的三档差异只有两个数字：

| 参数 | 新手 | 熟练 | 职业 |
|---|---|---|---|
| `iters`（蒙特卡洛抽样次数） | 200 | 500 | 900 |
| `mistake`（随机乱打概率） | 22% | 8% | 0% |

打法风格完全一样，**职业档只是"算得更准 + 不手滑"**，玩家打两把就能感觉出"这仨是同一个东西"。

---

## 二、思路：装能力开关，而不是调参数

把高手的本事拆成独立模块，按难度一个个打开：

| 能力 | 含义 | 新手 | 熟练 | 职业 |
|---|---|---|---|---|
| GTO 翻前表 | 查表决定开池 / 跟注 / 弃牌 | ✗ | ✓ | ✓ |
| 底池赔率 | 按赔率算该不该跟 | ✗ | ✓ | ✓ |
| 读人 | 统计对手 VPIP/PFR，调整松紧 | ✗ | ✓ | ✓ |
| 薄价值 | 中等牌力也主动下注收钱 | ✗ | ✓ | ✓ |
| 范围追踪 | 按对手的行动序列推断手牌分布 | ✗ | ✗ | 做了，**已关** |
| MDF 抓诈 | 面对小注不过度弃牌 | ✗ | ✗ | 做了，**已关** |
| 下注尺度解耦 | 尺度和牌力脱钩 | ✗ | ✗ | 做了，**已关** |
| 慢打 / 二次开火 | 强牌过牌设陷阱、转牌继续开火 | ✗ | ✗ | 做了，**已关** |
| 随机失误 | 按概率出昏招 | 19% | 3% | 0 |
| 怕大注 | 面对大注直接弃 | 42% | — | — |

---

## 三、测试方法

自建对打赛 `开发工具/bench.js`：

- 5 个 AI 座位，性格统一设为「均衡」，**只变难度**，隔离风格变量
- 座位 0 放一个"普通玩家"陪练（小注跟、大注倾向弃、偶尔主动下注）
- 每手结束按净盈亏 ÷ 大盲记 BB，**每手重置 100BB**
- 三种难度洗牌分配座位，跑多轮取平均

### 三个曾把结论带偏的坑

1. **起点必须在扣盲注之前取。** 否则每手凭空多算 1.5BB × 6 人 = 9BB，60 手能凑出 +900BB 的假象。
2. **陪练的选择决定结论。** 最早用"从不弃牌的跟注站"，结果诈唬、抓诈、范围追踪三项能力**全部失效**，测出来最强的永远是"紧 + 稳定价值下注"。换成会弃牌的陪练后数据才可信。
3. **小样本会骗人。** 一次 2400 手的测试显示"去掉高级玩法后 hard +140.5 vs normal +86.2"，看起来是重大突破；加大到 7000/10500 手后差距缩到 +14。**BB/100 的抽样标准误在千手量级约 ±60，任何小于 100 的差距都不能只看一轮。**

---

## 四、核心发现：GTO 化增强，打不赢弱玩家

### 消融实验结果（normal vs hard 单挑）

| hard 的配置 | normal | hard | 判断 |
|---|---|---|---|
| 全部增强打开（范围追踪 + MDF + 随机尺度 + 慢打 + 二次开火 + 剥削） | +102.5 | +74.3 | ❌ 更弱 |
| 关掉随机尺度与 MDF | +96.8 | +96.4 | ⚠️ 持平 |
| 再加"价值尺度 +15%" | +107.5 | +84.3 | ❌ 更弱 |
| 只留范围追踪（去掉全部"高级玩法"） | +86.2 | +140.5 | 小样本，见坑 3 |
| **范围追踪也关掉（最终方案）** | **+104.2** | **+118.4** | ✅ 大样本，见下表 |

最终方案样本：normal 10500 手 / hard 7000 手（7 轮 × 500 手）。

### 为什么"更专业"反而更弱

1. **对弱玩家的钱来自价值下注，不是平衡。** 职业选手的混合策略是拿来对付会思考的对手的；对面是个看到大注才弃牌的玩家，平衡毫无意义。
2. **诈唬要成立，对手弃牌率得高过 `bet/(pot+bet)`。** 弱玩家达不到这个门槛，多诈唬就是多送。
3. **慢打、二次开火在弱玩家身上是白送。** 他本来就会跟，你过牌只是少收一条街。
4. **范围追踪会低估自己的胜率。** 模型假设"对手下注 = 强牌多"，但真实对手的下注范围比模型宽得多，结果 AI 高估对手牌力、**过度弃牌**，越"聪明"亏得越多。这一项单独测都是负收益。

> 一句话：**GTO 是防守武器，剥削才是进攻武器。** 对弱玩家，简单直接的"紧 + 狠价值"就是最优解；想变强，方向是"少犯错 + 多榨价值"，不是"加更多高级模块"。

## 五、最终三档

```js
easy:   { mistake: 0.19, iters: 280,  blur: 0.52, noGto: true,  noOdds: true,  noRead: true,  noRange: true, noMdf: true, fixedSize: true,  scare: 0.42 }
normal: { mistake: 0.03, iters: 1200, blur: 0.00, noGto: false, noOdds: false, noRead: false, noRange: true, noMdf: true, fixedSize: true,  pro: true }
hard:   { mistake: 0.00, iters: 1800, blur: 0.00, noGto: false, noOdds: false, noRead: false, noRange: true, noMdf: true, fixedSize: true,  pro: true }
```

注意三档全部 `noRange: true / noMdf: true / fixedSize: true`——这三项是上面消融实验里被证明**负收益**的能力，代码保留但默认关闭。想复现实验，改这三个开关即可。

| 档位 | 定位 | 它缺什么 |
|---|---|---|
| 新手 | 完全不会玩 | 不查表、不算赔率、不读人，19% 乱打，见大注就怂（42% 直接弃），不爱主动下注 |
| 熟练 | 会打但会失手 | 全套基本功，但保留 3% 的随机失误 |
| 职业 | 会打且不失手 | 零失误 + 每步多算 600 次胜率 |

同性格、同牌局下实测（8 轮 × 400 手，普通玩家陪练，每手重置 100BB）：

```
easy   +34.67 BB/100（6400 手）
normal +112.31 BB/100（6400 手）
hard   +249.09 BB/100（3200 手）
```

**怎么看这组数字**：
- 三档单调递增，职业档是新手档的 7.2 倍，这个方向是稳的。
- 但**单轮方差极大**：同样是职业档，3 轮 × 400 手跑出过 +53.67，4 轮 × 400 手跑出过 +296.41。原因是 6 人桌每轮只能放 1 个职业座位，位置运气（BTN 赚钱 / BB 亏钱）会主导单轮结果。
- 所以报告里只用跑满 8 轮、职业档累计 3200 手的数字。**任何小于 100 BB/100 的差距都不能只信一轮。**

## 六、诚实的结论

**三档现在确实拉开了：`easy +34.67` / `normal +112.31` / `hard +249.09`（BB/100）。**

但差距的来源要说清楚，别误会成"AI 变聪明了"：

- 职业档**没有**比熟练档多任何"高级策略"。两者跑的是同一套代码、同一套 GTO 表、同一套翻后规则。
- 唯一的差别是：职业档**零失误**、每步多算 600 次胜率（1200 → 1800）。
- 也就是说，这 137 BB/100 的差距，几乎全部来自"熟练档那 3% 的失误"和"抽样精度"，不是来自"更会读牌"。

**结构性天花板仍然存在**：

- 当前 AI 的上限由"蒙特卡洛胜率 + 固定阈值规则"决定。真正的差距需要翻后范围求解（CFR / 预求解查表），体积和性能都扛不住，已明确排除。
- 我实现并实测过的所有"更 GTO"的组件（范围追踪、MDF、随机尺度、慢打、二次开火、剥削模块）**全部是负收益**，详见第四节。

**对玩家的体感**：简单档能赢、普通档要动脑、困难档几乎不给机会。这个层次是成立的。

## 七、和真人对局的差距

### 已经做到的

- **翻前**：查 26 个 GTO 场景表（8-max MTT 数据，MIT 许可），按位置和加注次数选范围，单挑模式自动放宽
- **翻后**：实时蒙特卡洛算胜率，按赔率决定跟弃，会打薄价值、会 C-bet、会读对手松紧
- **性格**：7 种打法（均衡 / 紧凶 / 松凶 / 紧弱 / 松弱 / 跟注站 / 疯子），每局随机分配且**不显示给玩家**，靠行为自己暴露
- **心智**：会记仇（tilt）、会变节奏、话术随牌力变化

### 还差什么（按影响排序）

1. **尺度泄露牌力。** 下注大小与胜率强相关，会读尺度的玩家能反推你的牌。真人会用同一尺度打诈唬和价值。
2. **诈唬频率偏低（约 11%）。** 真人 25–35%。不过已验证：对弱玩家提频是亏的，这是"像人"和"赢钱"的取舍。
3. **从不慢打。** 强牌必下注，转牌过牌基本等于放弃。
4. **翻后没有真正的范围建模。** 试过一版，因为会把对手想得太强而过度弃牌，已关闭。
5. **河牌没有抓诈机制。** 面对大注基本必弃，会被有耐心的玩家无限诈唬。

### 体感评估

- **完全不会玩的休闲玩家**：输 30–50 BB/100，一小时能感觉"这 AI 不好惹"
- **懂基础赔率的玩家**：2–3 小时摸透尺度规律，可以稳定赢
- **会读尺度的玩家**：能稳定剥削，因为第 1 条漏洞没堵上

---

## 八、已知限制

- 翻后不做真正的 GTO 求解（体积或性能都扛不住），用的是蒙特卡洛 + 启发式
- 三档的 BB/100 对比受样本量限制，只有方向性结论
- 难度只影响"算得多准、会不会犯错、看不看范围"，不改变性格
